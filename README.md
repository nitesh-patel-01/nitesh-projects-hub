# Nitesh Projects Hub

A fast, static directory of every public website and web tool by Nitesh Patel.

- 18 projects, grouped by category, with search and filters
- SEO: unique title/meta, semantic HTML, FAQPage + WebSite schema
- AEO: direct-answer FAQ section and `llms.txt` for AI search engines
- No framework, no tracking scripts, no build step — deploy the folder as-is on Vercel
